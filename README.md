# Dungeon Fighter
Created for my A-Level OCR Computer Science NEA
A python 2D top-down game in which the player can fight against rooms of zombies through a procedurally generated environment, with a goal of reaching a new top score and having fun.

To use, you must install the pygame module, which can be installed using pip install pygame in the terminal
Then, you must run the run.py file located in the main files folder
